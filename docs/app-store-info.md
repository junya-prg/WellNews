### プロモーション用テキスト（170文字以内）
```text
最新の健康・ウェルネスニュースをAIがスマートに要約＆カテゴリ分類！
健康ラジオ機能で、移動中や作業中もニュースを「ながら聴き」できます。
```

### 概要（4,000文字以内）
```text
スマートに健康習慣をアップデート。
健康・ウェルネス情報の収集と「ながら聴き」をサポートする「WellNews」。

--------------------
■ AIによるスマートなニュース要約
--------------------

信頼性の高い複数のメディアや公式情報から、最新の健康・ウェルネスニュースを自動で収集。
さらにAI対応端末では、記事の要約をAIが自動生成します。

・運動、食事・栄養、睡眠・休養、メンタルケアなどのカテゴリにAIが自動分類
・AIが重要度やパーソナライズされたおすすめ度を自動計算
・最新情報を視覚的に見やすく整理されたデザインで閲覧可能
（※AI機能はiOS 26.0+の対応端末で自動動作します。非対応端末ではキーワードマッチ等のフォールバック機能が稼働します）

--------------------
■ 健康ラジオで「ながら聴き」
--------------------

ニュースタイトルと要約をプロフェッショナルな音声合成で連続再生。
移動中、ウォーキング中、あるいは家事の合間にも、耳から最新の健康情報を取り入れることができます。

・タップするだけで流れる「ラジオ再生」
・1.0倍〜2.0倍の再生速度変更機能
・バックグラウンド再生対応。画面を閉じても快適に聴き続けられます

--------------------
■ 関心のあるキーワードでパーソナライズ
--------------------

「睡眠改善」「プロテイン」「サウナ」「血圧」など、あなたが気になるキーワードを登録。
関連するニュースを自動で抽出し、ニュースフィードに反映します。自分だけの健康情報誌を作りましょう。

--------------------
■ ブックマークでいつでも保存
--------------------

気になった記事や、後でゆっくり聴き直したいニュースはワンタップでブックマーク。
いつでもすぐにアクセスして読み返すことができます。

--------------------
■ プレミアムプランで全制限を解除
--------------------

買い切り型のプレミアムプランを導入することで、以下のすべての機能制限を解除できます：

・アプリ内のすべての広告（ネイティブ広告、バナー広告）の完全非表示
・健康ラジオの連続再生上限（無料版は5件まで）を解除し、無制限に再生可能
・追跡キーワードの追加制限（無料版は10個まで）を解除し、無制限に追加可能

--------------------
■ 開発者支援（Tip Jar）
--------------------

本アプリは個人のインディー開発者によって継続的に改善・運営されています。
もし気に入っていただけましたら、設定画面の「開発者支援」からコーヒー1杯分の寄付をいただけると大きな励みになります。

--------------------
■ こんな方におすすめ
--------------------

・忙しい毎日の中で、効率よくヘルスケア知識をインプットしたい方
・ウォーキングやランニング中に耳から健康情報を取り入れたい方
・特定の健康キーワード（ダイエット、筋トレ、睡眠等）に関心がある方
・自分のライフスタイルに合ったニュースフィードを構築したい方

--------------------
■ プライバシーと安全性
--------------------

ユーザーの登録キーワードやブックマークデータは、すべてデバイス内の安全な領域に保存されます。
第三者へ個人データが送信されたり販売されたりすることは一切ありません。
```

## GitHub Pages 設定手順

1. `WellNews` のGitHubリポジトリの設定（Settings）-> **Pages** を開きます。
2. Build and deployment の Source で **「Deploy from a branch」** を選択します。
3. Branch で **「main」** とフォルダ **「/docs」** を選択し、**「Save」** をクリックします。
