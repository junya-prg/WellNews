# WellNews

iOS 26+ のオンデバイスAI (Apple Intelligence) を活用し、自分仕様にパーソナライズされた健康・ウェルネスニュースキュレーションを提供するiOSアプリケーション。
（SmoPace の AIニュース機能を切り出し、単体アプリ化したプロジェクト）

AI非対応の機種やシミュレータ環境でも、自動的にキーワードベースの代替処理に切り替わるため、すべてのデバイスで快適にニュース閲覧やレベルアップ機能を楽しめます。

---

## 🌟 主な機能
1. **健康追跡キーワード管理**  
   ユーザー自身が追跡したい健康に関するキーワード（例: `睡眠改善`, `糖質制限`, `筋トレ`, `サウナ健康`, `マインドフルネス`）を自由に追加・削除できます。
2. **自動ニュースRSS取得**  
   設定されたキーワードをもとに、Google News RSS や はてなブックマーク から関連性の高いニュースを並列で高速取得。重複を排除して最新順にまとめます。
3. **オンデバイスAIによる分析とフォールバック (`FoundationModels`)**  
   * **AI対応機種 (Apple Intelligence)**:
     * **AI要約**: 記事本文を2〜3文の簡潔な日本語に要約。
     * **カテゴリ分類**: 記事を「運動」「食事・栄養」「睡眠・休養」「メンタルケア」「その他」に自動分類。
     * **おすすめ度判定**: ユーザーの関心プロフィールと記事内容を照らし合わせ、関連度スコア (0.0〜1.0) を算出。
   * **AI非対応機種 (自動フォールバック)**:
     * **概要表示**: AI要約の代わりに、RSSが配信する元記事の説明文（description）を自動配置。
     * **ルールベース分類**: タイトルや本文中の語彙（走、食、眠、マインド 等）を自動検出し、対応する健康カテゴリへ自動分類。
     * **ルールベースおすすめ度**: ユーザーの関心カテゴリや登録キーワードと記事テキストの一致度を計算し、おすすめ度 (0.0〜1.0) を算出。
4. **ウェルネス・ダッシュボード (ゲーミフィケーション)**  
   記事を読み進めるごとに「健康の苗木」がレベルアップ。種から双葉、若木、大樹、そして伝説の健康大樹へとレベルアップしていく進捗を視覚的に楽しめます。
5. **ブックマーク＆オフライン閲覧**  
   ためになる記事をブックマークしておけば、オリジナル記事がRSSから流れて消えてしまっても、要約やカテゴリ情報を含めて永続的に手元に保存・閲覧できます。

## 🚀 開発の進め方
本プロジェクトは Swift および SwiftUI で構成された iOS アプリプロジェクトのソースコードが揃っています。
Xcodeを起動して新規 SwiftUI iOSアプリプロジェクトを作成し、`WellNews` フォルダ内のソースコードを取り込むことでビルドが可能です。

* **デバイス互換性**:
  * 実機でオンデバイスAI機能を動作させるためには、iOS 26.0以降のOSを搭載し、Apple Intelligenceに対応したデバイスが必要です。
  * **非対応デバイスでも自動でマッチングロジックに切り替わるため、ビルドエラーやアプリ起動エラーは発生しません。**
